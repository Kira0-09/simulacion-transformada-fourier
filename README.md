# Simulación y análisis de señales con la transformada de Fourier

## Descripción
Este proyecto realiza la simulación y el análisis de diferentes señales mediante la Transformada Rápida de Fourier (FFT), utilizando Python.

## Objetivo
Analizar señales en el dominio del tiempo y de la frecuencia para comprender las propiedades de la transformada de Fourier.

## Señales analizadas
- Pulso rectangular.
- Función escalón.
- Señal senoidal de 50 Hz.

## Herramientas utilizadas
- Python 3.
- NumPy.
- Matplotlib.

## Instalación de bibliotecas
Para instalar las bibliotecas necesarias, ejecuta en la terminal:

```bash
pip install numpy matplotlib
```

## Cómo ejecutar el programa
1. Instalar Python 3.
2. Instalar NumPy y Matplotlib.
3. Abrir una terminal en la carpeta donde se encuentra el archivo.
4. Ejecutar el comando:

```bash
python simulacion_fourier.py
```

## Resultados esperados
El programa muestra gráficas de las señales en el dominio del tiempo, sus espectros de magnitud y fase, y comparaciones para observar propiedades de la transformada de Fourier.

## Conclusión
La simulación permite comprender cómo la transformada de Fourier representa las señales mediante sus componentes de frecuencia y cómo determinadas modificaciones de una señal se reflejan en su espectro.
